API Info

01 / INSTALL

From download to pool.

  1. Extract APIInfo_v1.0.3.zip.
  2. Copy APIInfo into your drive’s grandMA3/gma3_library/datapools/plugins/ folder.
  3. Edit a plugin pool slot, choose Import, then select API_Info_v1.0.3.xml.
  4. Close the editor and run the plugin.

The archive includes the release’s original metadata and assets. Follow the included README for plugin-specific instructions.

02 / RELEASE

About this revision.

Read-only grandMA3 diagnostic that selects the first external drive and exports current API and session/network information to grandMA3/gma3_library/datapools/plugins/APIInfo.
