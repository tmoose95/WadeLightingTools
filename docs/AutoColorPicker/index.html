01 / INSTALL

From download to pool.

  1. Extract AutoColorPicker_v5.0.3.zip.
  2. Copy AutoColorPicker into your drive’s grandMA3/gma3_library/datapools/plugins/ folder.
  3. Edit a plugin pool slot, choose Import, then select AutoColorPicker_v5.0.3.xml.
  4. Close the editor and run the plugin.

The archive includes the release’s original metadata and assets. Follow the included README for plugin-specific instructions.

02 / RELEASE

About this revision.

Zero-setup current-Data-Pool color picker. Automatically discovers Groups and Color presets, creates a managed Layout and collision-safe Macros using command-line pool indexes, embeds all runtime code and visual resources, remembers selections per user and Data Pool, and rebuilds only its own objects.
