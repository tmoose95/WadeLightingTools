01 / INSTALL

From download to pool.

  1. Extract Cue_Beacon_v1.0.0.zip.
  2. Copy Cue_Beacon_v1.0.0 into your drive’s grandMA3/gma3_library/datapools/plugins/ folder.
  3. Edit a plugin pool slot, choose Import, then select Cue_Beacon.xml.
  4. Close the editor and run the plugin.

The archive includes the release’s original metadata and assets. Follow the included README for plugin-specific instructions.

02 / RELEASE

About this revision.

Cue-driven executor beacon. Adds start/stop commands to cues in the selected sequence and pulses a chosen executor red until the configured stop cue.
