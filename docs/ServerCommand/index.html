01 / INSTALL

From download to pool.

  1. Extract ServerCommand_v2.3.15.zip.
  2. Copy ServerCommand into your drive’s grandMA3/gma3_library/datapools/plugins/ folder.
  3. Edit a plugin pool slot, choose Import, then select Server_Command_v2.3.15.xml.
  4. Close the editor and run the plugin.

The archive includes the release’s original metadata and assets. Follow the included README for plugin-specific instructions.
