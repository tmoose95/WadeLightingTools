01 / INSTALL

From download to pool.

  1. Extract TouchConfigurator_v1.0.41.zip.
  2. Copy TouchConfigurator into your drive’s grandMA3/gma3_library/datapools/plugins/ folder.
  3. Edit a plugin pool slot, choose Import, then select TouchConfigurator_v1.0.41.xml.
  4. Close the editor and run the plugin.

The archive includes the release’s original metadata and assets. Follow the included README for plugin-specific instructions.
