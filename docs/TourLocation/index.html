01 / INSTALL

From download to pool.

  1. Extract TourLocation_v1.0.10.zip.
  2. Copy TourLocation into your drive’s grandMA3/gma3_library/datapools/plugins/ folder.
  3. Edit a plugin pool slot, choose Import, then select TourLocation_v1.0.10.xml.
  4. Close the editor and run the plugin.

The archive includes the release’s original metadata and assets. Follow the included README for plugin-specific instructions.

02 / RELEASE

About this revision.

Searchable worldwide touring-city presets with venue references. Applies session timezone, automatic DST offset, latitude, and longitude; enables and verifies NTP with time.google.com; verifies GlobalMaster authority before reporting success; supports saved defaults and keyboard-only operation.
