01 / INSTALL

From download to pool.

  1. Extract WLT Plugin Updator_v1.1.4.zip.
  2. Copy WLT Plugin Updator into your drive’s grandMA3/gma3_library/datapools/plugins/ folder.
  3. Edit a plugin pool slot, choose Import, then select WLT Plugin Updator_v1.1.4.xml.
  4. Close the editor and run the plugin.

The archive includes the release’s original metadata and assets. Follow the included README for plugin-specific instructions.

THE UPDATE WORKFLOW

Scan. Compare. Update.

01

Scan connected drives

Only current internal and connected USB plugin libraries are scanned. With no USB attached, the scan stays internal. Old software drives are skipped.

02

Choose your updates

Showfile, USB Drives and More Plugins tabs. Green versions match the live catalog; red versions differ. Unknown versions stay grey.

03

Choose how to install

Choose Import Online, Download to Drives or Import from Drive for each plugin. Review the queued actions and target DataPools before applying.

Version 1.1.4 adds a moving progress bar with percentage, transfer progress, and a compact native System Monitor view during updates. An existing empty Lua component can be repaired from a verified package after preserving its damaged snapshot and confirming the repair. More Plugins retains per-plugin QR pages. Efficient scanning, self-contained show-pool imports and Lua readback verification remain in place. Console HTTPS includes a Mozilla certificate bundle. Connection Details reports the actual error if catalog access fails. The updater has automated test coverage; native console import, touch and transport behavior still require on-console testing.
