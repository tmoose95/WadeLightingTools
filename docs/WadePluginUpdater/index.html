01 / INSTALL

From download to pool.

  1. Extract WLT Plugin Updator_v1.0.3.zip.
  2. Copy WLT Plugin Updator into your drive’s grandMA3/gma3_library/datapools/plugins/ folder.
  3. Edit a plugin pool slot, choose Import, then select WLT Plugin Updator_v1.0.3.xml.
  4. Close the editor and run the plugin.

The archive includes the release’s original metadata and assets. Follow the included README for plugin-specific instructions.

02

03

Choose how to install

Download & Install, Download Only, or Install Only using complete packages already on a selected drive.

Internet updates require this GitHub repository to be published and a supported HTTPS client on the station. The updater has automated test coverage; native console import, touch and transport behavior still require on-console testing.
