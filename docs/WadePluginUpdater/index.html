01 / INSTALL

From download to pool.

  1. Extract WLT Plugin Updator_v1.1.8.zip.
  2. Copy WLT Plugin Updator into your drive’s grandMA3/gma3_library/datapools/plugins/ folder.
  3. Edit a plugin pool slot, choose Import, then select WLT Plugin Updator_v1.1.8.xml.
  4. Close the editor and run the plugin.

The archive includes the release’s original metadata and assets. Follow the included README for plugin-specific instructions.

02 / RELEASE

About this revision.

THE UPDATE WORKFLOW

Scan. Compare. Update.

01

Scan plugin libraries

Only current internal and connected USB plugin libraries are scanned. Without USB, the Drives tab still shows internal packages. Old software drives are skipped.

02

Choose the destination

Showfile offers Import from Drive and Import from Internet. Both are visibly paused while the console restart is investigated. Drives offers Download from Internet only for plugins already found on a connected drive. WLT Plugin Updator itself is always free to download.

03

Follow the download

Tabs retain separate action queues. Downloads verify checksums and preserve drive backups. A progress bar and the last three updater activity messages show progress.

Version 1.1.8 removes the unverified embedded native System Monitor window. The available crash log records a native memory-access fault, but does not establish its cause or confirm that the import step was reached. Showfile imports and self replacement remain blocked pending native validation. This is not a claim that the crash is fixed. The activity panel shows only the updater's messages, not the full System Monitor stream. The supplied macOS grandMA3 app cannot run on this Linux build host.
