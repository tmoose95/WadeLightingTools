01 / INSTALL

From download to pool.

  1. Extract WLT Plugin Updator_v1.1.0.zip.
  2. Copy WLT Plugin Updator into your drive’s grandMA3/gma3_library/datapools/plugins/ folder.
  3. Edit a plugin pool slot, choose Import, then select WLT Plugin Updator_v1.1.0.xml.
  4. Close the editor and run the plugin.

The archive includes the release’s original metadata and assets. Follow the included README for plugin-specific instructions.

THE UPDATE WORKFLOW

Scan. Compare. Update.

01

Scan connected drives

Internal and removable drives are scanned before the main window opens.

02

Choose your updates

Showfile, USB Drives and More Plugins tabs. Green versions match the live catalog; red versions differ. Unknown versions stay grey.

03

Choose how to install

Choose Import Online, Download to Drives or Import from Drive for each plugin. Review the queued actions and target DataPools before applying.

Console HTTPS supports OpenSSL without the separate timeout utility and includes a Mozilla certificate bundle. Connection Details reports the actual error if catalog access fails. The updater has automated test coverage; native console import, touch and transport behavior still require on-console testing.
