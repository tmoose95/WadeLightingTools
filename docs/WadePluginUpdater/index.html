01 / INSTALL

From download to pool.

  1. Extract WLT Plugin Updator_v1.1.6.zip.
  2. Copy WLT Plugin Updator into your drive’s grandMA3/gma3_library/datapools/plugins/ folder.
  3. Edit a plugin pool slot, choose Import, then select WLT Plugin Updator_v1.1.6.xml.
  4. Close the editor and run the plugin.

The archive includes the release’s original metadata and assets. Follow the included README for plugin-specific instructions.

THE UPDATE WORKFLOW

Scan. Compare. Update.

01

Scan connected drives

Only current internal and connected USB plugin libraries are scanned. With no USB attached, the scan stays internal. Old software drives are skipped.

02

Choose your updates

Showfile, USB Drives and More Plugins tabs. Green versions match the live catalog; red versions differ. Unknown versions stay grey.

03

Choose how to install

Choose Download to Drives for each plugin. Automated showfile imports, including self replacement, are temporarily disabled after a console restart report.

Version 1.1.6 is a containment release. A console restart was reported when importing any plugin from a drive through v1.1.5. Both automated showfile import routes are blocked, including updater self replacement. This does not establish the crash cause or claim a native import fix. Downloads still verify checksums and preserve drive backups. Scanning, version colors, QR pages and download progress remain available. Do not retry the affected import operation on a production console. The build environment cannot run the supplied macOS grandMA3 app; native MA3 2.5.1 validation is still required.
